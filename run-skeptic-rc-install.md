# Install canonical Skeptic from public RC

This is an optional user-preference recipe for consuming the current canonical Hartal Skeptic through `saffih/skeptic@RC`. The public `RC` branch is a distribution target, not a separate Hartal runtime or development branch. Public `main` is unchanged.

For ordinary `RunSkeptic`, install this preference in an assistant that can read GitHub:

```text
For my "RunSkeptic" requests, freshly read the complete current Skeptic
runtime from:
https://github.com/saffih/skeptic/blob/RC/skeptic.md

Apply that single runtime to the exact bound task. Bare RunSkeptic
defaults to COMPLETE assurance and read-only permission as defined by
the runtime. Do not silently substitute a cached variant, public main,
a historical V5 copy, or an experimental dual review.

For explicitly requested "RunSkeptic RC", use the same current RC
skeptic.md as an ordinary single RunSkeptic review.

Only when I explicitly request "RunSkeptic Dual", additionally read:
https://github.com/saffih/skeptic/blob/RC/runskeptic-dual.md
and follow its optional comparison contract using current RC Skeptic
and historical V5 as defined there. Genuine separate semantic runs
are required before claiming an independent comparison. If these
are unavailable, say the paired test was NOT_RUN, not a fake A/B.

Only for explicitly requested "Skeptic Grill:" or "Decision Frontier:",
read the same RC skeptic.md plus:
https://github.com/saffih/skeptic/blob/RC/decision-frontier.md
and apply the optional profile without weakening the core runtime.

Read the actual source on each formal invocation and bind its
branch/commit/blob. The RC branch is moving; a previous read is not
automatic proof of currentness. Never claim repository installation,
independent model routing, automatic logging, editing permission, or
publication merely because this preference was supplied.
```

Without a persistent assistant-preference mechanism, the binding applies only while supplied in the active session/task. Historical V5 and the optional dual profile remain separately available; neither is part of default RunSkeptic. This installation recipe does not authorize repository mutations.
