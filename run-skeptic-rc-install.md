# Install Skeptic V8 from public RC

This is an optional user-preference recipe for consuming experimental V8 from `saffih/skeptic@RC`, sourced from Hartal's V8 candidate branch. Public stable `main` remains V7. Selecting public `RC` is explicit; this recipe does not change another environment's runtime binding.

For ordinary `RunSkeptic`, install this preference in an assistant that can read GitHub:

```text
For my "RunSkeptic" requests, freshly read the complete experimental V8
Skeptic runtime from:
https://github.com/saffih/skeptic/blob/RC/skeptic.md

Apply that single runtime to the exact bound task. Bare RunSkeptic
defaults to COMPLETE assurance and read-only permission as defined by
the runtime. Do not silently substitute a cached variant, public main,
a historical V5 copy, or an experimental dual review.

For explicitly requested "RunSkeptic RC", use the same current RC
skeptic.md as an ordinary single RunSkeptic review.

When I explicitly say SKEXT or Skeptic Next, read
https://github.com/saffih/skeptic/blob/RC/AGENTS.md
and follow its SKEXT shortcut using the current RC runtime.
Incidental mentions do not invoke it.

Only when I explicitly request "RunSkeptic Dual", additionally read:
https://github.com/saffih/skeptic/blob/RC/runskeptic-dual.md
and follow its optional comparison contract using V8 RC Skeptic
and frozen stable V7 as defined there:
https://github.com/saffih/skeptic/blob/RC/skeptic-v7.md
Genuine separate semantic runs
are required before claiming an independent comparison. If these
are unavailable, say the paired test was NOT_RUN, not a fake A/B.

Only for explicitly requested "Skeptic Grill:" or "Decision Frontier:",
read the same RC skeptic.md plus:
https://github.com/saffih/skeptic/blob/RC/decision-frontier.md
and apply the optional profile without weakening the core runtime.

For each formal invocation, show the compact RunSkeptic source/receipt.
When activated DMR exercises RSC (Recurrence Sufficiency Check),
report RSC TRIGGERED with evidence, result and decision impact.
For a later 'Skeptic Trace' request, inspect existing receipts and
report invocation, DMR/RSC triggers and impact; if unavailable say UNKNOWN.
Do not invent retrospectively triggered features.

Read the actual source on each formal invocation and bind its
branch/commit/blob. The RC branch is moving; a previous read is not
automatic proof of currentness. Never claim repository installation,
independent model routing, automatic logging, editing permission, or
publication merely because this preference was supplied.
```

Without a persistent assistant-preference mechanism, the binding applies only while supplied in the active session/task. Frozen stable V7 is the optional comparison control; historical V6 and V5 remain available for reference. None is part of the selected RC's default RunSkeptic. This installation recipe does not authorize repository mutations.
