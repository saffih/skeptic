# TP Brain Agent

TP Brain is defined by `workflows/task_prompt.md`, which is the complete and
only authority for the Task Prompt workflow. Read that file's "TP Brain"
section for this role's ownership, inputs, supporting delegation, output, and
boundaries.

This file is a routing stub and carries no authority of its own. It exists only
so that a reference to `agents/tp_brain.md` resolves to the owning authority.

TP Brain is Task-Prompt-specific. It is not a generic planning role, it does
not replace `agents/planner.md` for non-TP work, and no other workflow acquires
it by reference.
